# CAT Data Flywheel (Standard)

Capture (voice or text)
  → Structure (extraction / validation)
  → Local store (SQLite / IndexedDB)
  → Optional consented sync (Supabase / edge)
  → Natural language query & insight
  → Improved capture prompts, models, and edge behaviour

## Principles

- Local-first by default.
- Cloud aggregation only with explicit consent and NZ residency preference.
- Every domain log (scaffold journals, microgreens telemetry, soil readings, etc.) should be able to feed the same flywheel shape.
- Insights must cite sources back to the underlying structured records.
