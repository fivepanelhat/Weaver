# Skills (public evaluation layer)

Coastal Alpine Tech maintains a fleet of **93 named, versioned skills**. They are customisable for any industry under the same HITL and Te Mana Raraunga contract.

This public repository shows **one working set** that matches Weaver — the **Edge / orchestration set**:

- `kiwi-edge-architecture`
- `edge-node-commissioning`
- `cat-model-sentinel`
- `cat-egress-sentinel`
- `cat-doctor`

Plus the standing safety stack: `aether-core`, `cat-architectural-standards`, `aether-hitl-protocol`.

Full procedures, commissioning worksheets, and scored playbooks are not published here. They load from the private CAT Agent Harness under a written agreement.

Humans still advise, decide, sign, file, send, and pay. A skill cannot raise that ceiling.
